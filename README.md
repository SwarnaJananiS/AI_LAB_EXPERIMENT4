# AI_LAB_EXPERIMENT4
AI Lab Experiment using Python
Experiment 4: Student Record Management Using Lists, Tuples, Dictionaries, Files and CSV

Aim:
To develop a student record management system using Python lists, tuples, dictionaries, text file handling, and CSV file processing.

Concepts Used:
- Lists and dictionaries
- Tuples
- File handling
- CSV file processing
- Python "csv" module
- Reading and writing files

Description:
The program stores student records containing roll numbers, names, departments, and marks. It demonstrates the use of a tuple for fixed course details, writes student records to a text file and a CSV file, and reads the CSV file to display the stored records.

Files Generated:
- "students.txt" — Stores student records as text.
- "students.csv" — Stores student records in CSV format.

How to Run:
python experiment4.py

Requirement: Python 3. The "csv" module is included in the Python standard library.

Sample Output:
Course Tuple: ('Python', 4)

--- Records from CSV ---
101 Anitha CSE 86
102 Bala CSE 91
103 Chitra ECE 78

Result

A student record management system using lists, tuples, dictionaries, file handling, and CSV processing was implemented successfully.
